KWIX — Android ऐप (सबके लिए: खरीदार और सेलर दोनों)
====================================================
यह ऐप पूरी kwix.shop वेबसाइट को ऐप के रूप में खोलता है — होम पेज से।
खरीदार गाड़ियाँ देख सकते हैं, WhatsApp/Call दबा सकते हैं; सेलर लॉगिन करके
अपना डैशबोर्ड चला सकते हैं। लॉगिन याद रहता है, फ़ोटो गैलरी/कैमरा से डाल सकते हैं।
वेबसाइट में जो बदलेगा, ऐप में अपने-आप दिखेगा — ऐप दोबारा बनाने की ज़रूरत नहीं।

ऐप का नाम: Kwix      पैकेज: shop.kwix.app
(पुराना "Kwix Seller" ऐप अलग है — दोनों एक फ़ोन में साथ रह सकते हैं।)

APK बनाने के तीन तरीके (कोई एक चुनें)
-------------------------------------
तरीका 1 — GitHub (कुछ इंस्टॉल नहीं करना):
  1. github.com पर नया repository बनाएँ, इस फ़ोल्डर की सारी फ़ाइलें अपलोड करें
     (.github फ़ोल्डर भी)।
  2. Actions टैब → "Build APK" → Run workflow।
  3. 5-10 मिनट बाद रन खोलें → नीचे "kwix-apk" डाउनलोड करें।

तरीका 2 — Android Studio (कंप्यूटर पर):
  1. developer.android.com/studio से Android Studio इंस्टॉल करें।
  2. यह ज़िप एक्सट्रैक्ट करें → Android Studio → Open → यह फ़ोल्डर चुनें।
  3. "Gradle sync" पूरा होने दें (पहली बार 10-20 मिनट)।
  4. Build → Build App Bundle(s) / APK(s) → Build APK(s) → locate → app-debug.apk

तरीका 3 — सबसे आसान (ज़िप की ज़रूरत भी नहीं):
  pwabuilder.com खोलें → kwix.shop डालें → Package for stores → Android →
  APK डाउनलोड करें।

फ़ोन में इंस्टॉल
---------------
APK फ़ाइल खोलें → "Install unknown apps" की अनुमति दें → Install।
(Play Store से बाहर का ऐप है, इसलिए Android चेतावनी दिखाएगा — यह सामान्य है।)
