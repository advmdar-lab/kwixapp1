MB2B - Android app (for buyers and sellers)
===========================================
The app opens the mb2b.in website as an app, from the home page.
Buyers can see the ads, Call and Chat; sellers log in and run their shop.
The login is remembered, and photos can come from the gallery or the camera.
Whatever changes on the website shows in the app by itself; the app does not need to be built again for that.

Version 2 (October 2026):
- The app is called MB2B.
- The MB2B bar stays in the phone's notification panel, with Inbox, Buy Leads (or Saved) and Search buttons
  and the number of new messages.
- Every 15 minutes (when Android allows) the app checks mb2b.in for new messages and shows a notification.

App name: MB2B      Package: shop.kwix.app (kept, so Android knows it is the same app)

Build the APK on GitHub (nothing to install)
--------------------------------------------
1. Upload all the files of this folder to the GitHub repository (the .github folder too).
2. GitHub builds by itself after the upload. Or: Actions tab -> "Build APK" -> Run workflow.
3. After 5-10 minutes open the finished run -> at the bottom download "mb2b-apk" (a .zip with app-debug.apk inside).
4. Rename app-debug.apk to mb2b.apk and upload it to public_html on Hostinger.
   The "Download app" buttons on mb2b.in then give this new app.

Install on a phone
------------------
Open the APK file -> allow "Install unknown apps" -> Install.
If the phone has the old app, uninstall the old one first (each GitHub build has a new signature).
